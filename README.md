# iPhone 17 Pro

Landing page conceitual do iPhone 17 Pro, criada com React para fins de estudo. O projeto apresenta uma interface responsiva com navegação por seções, detalhes do produto e seleção de cores.

> Projeto educacional e não oficial da Apple. Textos, imagens e especificações são demonstrativos.

## Tecnologias

- React 19
- Vite
- JavaScript/JSX
- Tailwind CSS
- ESLint

## Executar localmente

```bash
npm install
npm run dev
```

Outros comandos disponíveis:

```bash
npm run build
npm run preview
npm run lint
```

## Publicação

## Estrutura

```text
public/img/       # Imagens do produto
src/components/   # Componentes da interface
src/App.jsx       # Composição principal
src/main.jsx      # Inicialização do React
vite.config.js    # Configuração do Vite
```
