# iPhone 17 Pro

Landing page do iPhone 17 Pro, criada com React para fins de estudo. O projeto apresenta uma interface responsiva com navegação por seções, detalhes do produto e seleção de cores.

> Projeto educacional e não oficial da Apple. Textos, imagens e especificações são demonstrativos.

## Tecnologias

- React 19
- Vite
- JavaScript/JSX
- Tailwind CSS
- ESLint
